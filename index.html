El proyecto

Ingenieria de datos aplicada al invernadero

El proyecto integra el trabajo experimental de cuatro tratamientos y cinco plantas por fila con variables ambientales y de crecimiento. El objetivo es garantizar datos confiables y listos para analitica avanzada.

ETL reproducible

Extraccion, limpieza y carga documentadas paso a paso, con trazabilidad de cada decision sobre el dato original.

Analisis exploratorio

Distribuciones, valores atipicos, correlaciones y evolución temporal para entender el comportamiento del cultivo.

Datos listos para ML

One Hot Encoding sobre las variables categoricas para entregar una matriz numerica apta para modelos predictivos.

Pipeline

Seis etapas, un solo flujo confiable

Cada etapa tiene una responsabilidad clara y produce un artefacto verificable.

1. ExtraccionCSV delimitado por ;
2. Limpiezatipos, fechas y nulos
3. AnalisisEDA y visualizacion
4. TransformacionOne Hot Encoding
5. PersistenciaCSV limpio y codificado
6. DespliegueStreamlit local y cloud
1

Extraccion e inspeccion

Lectura de Data_Mocollo1.csv con validacion de dimensiones, tipos y estructura de columnas.

2

Limpieza y normalizacion

Conversion de decimales europeos, fechas a formato ISO, nulos controlados y humedad normalizada al rango 0-1.

3

Analisis exploratorio

Histogramas, boxplots, densidades, series temporales y matriz de correlacion de Pearson.

4

Transformacion

Variables categoricas convertidas a columnas binarias con get_dummies.

5

Persistencia

Generacion de Data_Mocollo1_Limpio.csv y Data_Mocollo1_Transformado.csv.

6

Publicacion

Dashboard Streamlit con filtros por fecha, tratamiento, planta y responsable, mas el cuaderno ejecutable.

Calidad y decisiones

Reglas claras sobre el dato

La limpieza no borra informacion sin criterio: documenta y preserva la trazabilidad.

Hallazgos del dataset

  • 540 registros y 26 fechas entre el 14/09/2026 y el 02/11/2026.
  • 480 valores nulos en variables numericas, conservados como ausencia de lectura.
  • 60 registros de humedad normalizados de porcentaje a proporcion.
  • Completitud global del 85,2% sobre las seis variables numericas.
  • Sin duplicados en el dataset limpio.

Decisiones de transformacion

  • Fecha dd/mm/aaaa convertida a tipo datetime.
  • Coma decimal europea convertida a punto decimal.
  • Humedad relativa acotada al rango 0-1.
  • Outliers detectados por IQR: se senalan, no se eliminan.
  • Variables categoricas transformadas con One Hot Encoding.
  • Salidas exportadas en CSV limpio y CSV transformado.

Puesta en marcha

Ejecuta la plataforma en local

Crea un entorno virtual, instala las dependencias y abre la aplicacion en el navegador.

# Windows (PowerShell)
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m ipykernel install --user --name macollo --display-name "Macollo (venv)"
streamlit run app.py
# macOS / Linux
python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m ipykernel install --user --name macollo --display-name "Macollo (venv)"
streamlit run app.py
La aplicacion queda disponible en http://localhost:8501. Para desplegarla en Streamlit Cloud, publica el repositorio y selecciona app.py como archivo principal.
